# smoothwrite 公众号正文写作

根据论文元信息、文章计划、配图计划和 PDF 解析文本，生成完整的中文微信公众号科研解读正文。

遵循 `system_style.md` 的总写作规范。

## 写作要求

- 输出 Markdown。
- 第一行必须是文章标题，使用一级标题格式。
- 标题必须符合：`期刊｜研究对象/核心发现：机制概括/意义总结`。
- 引言第一句必须包含年份、月份、期刊、团队和英文论文标题。
- 英文论文标题必须使用 Markdown 斜体，例如：`*English Paper Title*`。
- 正文使用中文数字编号分节，例如：`## 一、短判断句`。
- 分节标题必须短，并表达明确判断，不能只是关键词。
- 每节使用适合手机端阅读的短段落。
- 每节可使用中文编号分点，例如：`1）`、`2）`、`3）`，说明证据或逻辑推进。
- 围绕“旧认知—新证据—新模型/新理解”展开，不要机械复述论文结果顺序。
- 在配图计划指定的合适位置插入配图标记，例如：`配图1｜Figure 1`。
- 配图标记必须独立成行，并与正文论点紧密相关。
- 文末需要有总结升华，说明该研究如何改变理解、留下哪些限制或新问题。
- 文末必须包含：
  - `论文信息：作者 et al., 期刊, 年份。`
  - `原文链接：...`

## 禁止事项

- 不要在正文中保留论文引用编号，如 `[1]`、`(1)` 或上标引用编号。
- 不要保留文件引用标记、网页引用标记或内部检索标记。
- 不要编造论文没有的数据、机制、结论或研究意义。
- 不要将相关性写成因果关系。
- 不要使用营销号、小红书、震惊体或过度口语化表达。

## 输出格式

只输出完整 Markdown 正文，不要输出写作说明、JSON、代码块或额外前后缀。
