# 成品、检查与公众号使用（v3）

## 输出

对用户只呈现 `preview.html` 和一句使用说明。其余文件由代理自用，不变成用户的额外步骤。

- `preview.html`：可编辑单文件，所有图片内嵌（可选内嵌原文 PDF 下载）。左侧工具栏：编辑文字与二维码、**复制到公众号**、下载可编辑草稿、下载纯正文 HTML、设置论文与往期链接。
- `body-article.html`：与“复制到公众号”内容一致的纯正文（Python 端生成），便于对照或手动复制。
- `article.md`：标题、导语、概述、图题与往期推荐的文字稿。
- `assets/`：压缩后的期刊截图、Fig、logo、二维码。
- `paper_metadata.json`、`evidence-map.tsv`、`content-contract.json`、`review_notes.md`、`output_manifest.json`：书目、证据页码、检查契约与核对记录。

## 自动检查（`validate`，`render` 后自动运行）

- 标题、导语、概述、课题组原文与 `content.json` 一致；Fig 数、往期推荐数、头图有无与契约一致；模块顺序为 概述 → 图示 → 往期推荐 → 课题组；不存在作者简介模块。
- 微信兼容：正文与复制体中没有 `svg/button/table/script/iframe`，没有 `display:table/flex/grid`、`position`、`object-fit`、`scroll-snap`、`calc()`；图片全部内嵌且短边 ≥150px；复制体不带 id/class；复制体 <5MB。
- 自动检查不证明科学表述正确、截图来源真实或视觉通过；这些靠阅读与实际预览确认。

## 视觉检查（浏览器工具可用时）

桌面与约 390px、320px 宽度：标题与长英文换行；Fig 横滑每张卡片完整、露出下一张；点图放大；编辑模式可改字；“复制到公众号”提示成功；往期推荐留空时检查标题和空行，已有条目时检查对应链接。工具不允许访问时停止该路线并如实说明。

## 微信后台

1. 用 Chrome / Edge 打开 `preview.html`，点“复制到公众号”，在后台正文区粘贴；标题填后台标题栏。
2. 粘贴后等待图片全部上传完成再保存（微信会把内嵌图片转存到素材库）。
3. 电脑端编辑器里横滑可能显示为一行；发手机预览确认左右滑动、点图放大。
4. 未认证公众号的正文外链可能不可点，可把论文链接放进“阅读原文”。往期推荐优先使用 `mp.weixin.qq.com` 链接。
5. 若某张图粘贴后仍为空白，先确认图片短边与体积（`validate` 会报出），必要时在后台手动上传该图。
6. 未获明确授权时，不自动登录公众号、导入、群发、发邮件或推送 GitHub。
